# Setup (El Abd concept)
From your business-site-template folder (Astro + Tailwind already set up, agents in .claude/):

1. Copy these into the project root, merging folders:
   client-brief.md, CLAUDE.md, SETUP.md, src/data/site.json, .claude/commands/new-site.md
2. git add -A && git commit -m "El Abd brief + content"
3. claude
4. /new-site
5. npm run dev  -> check it on desktop AND your phone (RTL on mobile is where it breaks)
6. Later: /ship add English/Arabic language toggle with full RTL/LTR switching, Arabic default
